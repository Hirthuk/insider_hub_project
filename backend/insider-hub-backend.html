Comprehensive Server-Side Architecture

Backend Overview

The Insider Hub backend is built with modern server technologies to provide a robust, secure, and scalable API for the frontend application. It handles user authentication, data management, email notifications, and business logic for the appreciation system.

Core Capabilities

  • User Authentication & Authorization - JWT-based secure login system
  • RESTful API Design - Clean, consistent API endpoints
  • Database Management - Efficient data storage and retrieval
  • Email Integration - Automated notifications and alerts
  • Middleware Security - Request validation and protection
  • Session Management - Secure user session handling

API Endpoints Overview

Authentication Endpoints

POST /api/auth/login - User login with SAPID and password
POST /newUser - User registration request
GET /logoutuser - User session termination

Core Feature Endpoints

GET /happenings - Retrieve all appreciation posts
POST /userappreciate - Submit appreciation message
POST /postlike - Like appreciation post
GET /userprofile - User profile data

Security Features

Authentication & Authorization

  • JWT Token System - Secure, stateless authentication
  • Password Encryption - Bcrypt hashing for password security
  • Role-Based Access - Different permissions for users and administrators
  • Session Management - Automatic token expiry and renewal

Data Protection

  • Input Validation - Server-side validation for all inputs
  • SQL Injection Prevention - Parameterized queries and ORM protection
  • CORS Configuration - Proper cross-origin resource sharing
  • Rate Limiting - API call frequency restrictions

Middleware Protection

  • Authentication Middleware - Token verification on protected routes
  • Error Handling - Centralized error processing and logging
  • Request Logging - Comprehensive request/response logging
  • Data Sanitization - Input cleaning and validation

Database Architecture

Core Tables

Users Table - SAPID, name, email, role, password, creation time
Appreciations Table - sender, recipient, message, timestamp, likes
Likes Table - user_id, appreciation_id, timestamp
Sessions Table - user_id, token, expiry, created_at

Key Features

  • Relational Design - Normalized database structure
