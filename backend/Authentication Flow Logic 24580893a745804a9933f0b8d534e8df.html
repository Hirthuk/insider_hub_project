Authentication Flow Logic

✅ 1. User Sends Login Request

Frontend → Backend:

POST /login
Content-Type: application/json

{
  "sapid": 123456,
  "password": "userPassword"
}

✅ 2. Backend Authenticates User

In your controller (/login endpoint):

Optional<UsersEntity> existingUser = userRepository.findBySapid(sapid);
if (existingUser.isPresent()) {
    UsersEntity user = existingUser.get();
    if (passwordEncoder.matches(password, user.getPassword())) {
        String role = user.getRole();
        String token = jwtUtil.generateToken(sapid, role);
        return Map.of("role", role, "token", token);
    }
    throw new RuntimeException("Invalid credentials");
}

🟢 If credentials match:

  • A JWT is generated using JwtUtil.
  • role is added as a claim.
  • Token is returned to the frontend.

✅ 3. Frontend Stores Token

Frontend (React/Angular/HTML+JS):

localStorage.setItem("token", response.token);

✅ 4. Frontend Sends Token With Requests

For every protected API call:

GET /user/dashboard
Authorization: Bearer <JWT_TOKEN>

✅ 5. Spring Security Intercepts Request

JwtAuthFilter is invoked automatically by Spring Security:

String header = request.getHeader("Authorization");
  • Checks if Authorization exists and starts with "Bearer ".

✅ 6. Token Is Extracted & Verified

String token = header.substring(7);
Claims claims = jwtUtil.extractAllClaims(token);

In JwtUtil.java:

return Jwts.parser()
        .verifyWith(SECRET_KEY)
        .build()
        .parseSignedClaims(token)
        .getPayload();
  • Validates the token's signature.
  • Extracts subject (sapid), role, issued time, expiration.

✅ 7. Spring Sets Authentication

String sapid = claims.getSubject(); // comes from token
String role = (String) claims.get("role");

SimpleGrantedAuthority authority = new SimpleGrantedAuthority("Role_" + role);
UsernamePasswordAuthenticationToken auth = new UsernamePasswordAuthenticationToken(sapid, null, List.of(authority));

SecurityContextHolder.getContext().setAuthentication(auth);

🔐 This step tells Spring Security:

"This user is authenticated and has this role."

✅ 8. Request Proceeds to Controller

Now the controller method is executed:

@GetMapping("/dashboard")
public ResponseEntity<?> dashboard(Principal principal) {
    return ResponseEntity.ok("Welcome " + principal.getName());
}
  • principal.getName() → The sapid extracted from the JWT.
  • Authorization checks (like @PreAuthorize("hasRole('ADMIN')")) now work automatically.
