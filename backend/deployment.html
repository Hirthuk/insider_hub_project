Example Dockerfile

FROM eclipse-temurin:17-jdk-alpine
WORKDIR /app
ARG JAR_FILE=target/*.jar
COPY ${JAR_FILE} app.jar
EXPOSE 8080
ENTRYPOINT ["java","-jar","/app/app.jar"]

Deploy steps (high level)

  1. Build JAR: mvn -DskipTests package
  2. Build image: docker build -t youruser/insider-backend:latest .
  3. Push to registry: docker push youruser/insider-backend:latest
  4. On Oracle VM: docker pull ... && docker run -d --name insider-backend -p 8080:8080 --restart unless-stopped -e SPRING_PROFILES_ACTIVE=prod youruser/insider-backend:latest
  5. Configure nginx reverse proxy and TLS (Certbot) for ports 80/443.

Notes

  • Keep secrets out of the image. Use env vars, docker secrets, or mounted files.
  • Match filenames and case exactly for GitHub Pages.
  • If Pages uses docs/, place this file in docs/backend and add docs/.nojekyll.
