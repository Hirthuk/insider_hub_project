Application Structure

Root Page

The landing page contains two main buttons:

  • Login - Routes to /login page
  • Request Access - Routes to /requestuser page

Login Page

Simple login form with SAPID and Password inputs

Upon Clicking Sign In Button:

POST /api/auth/login
Triggers backend API to validate user credentials

Request Access Page

Sign-up form with the following mandatory fields:

  • SAPID
  • Full Name
  • Designation
  • Project
  • Password
  • Confirm Password
  • Email ID

Note: Role, Creation time, and Unique ID are stored automatically.

Upon Clicking Request Access Button:

POST /newUser
Sends user data to administrators and triggers email notifications to all admins for approval

Home Page Features

After successful login, users access the main dashboard with 5 core options:

  • View Happenings - Browse all appreciation messages and team updates
  • Appreciate - Send appreciation messages to team members
  • Profile - Manage personal profile and view statistics
  • About - Project information and details
  • Logout - Secure session termination

Detailed Functionalities

View Happenings

  • Display all appreciation messages between teams and employees
  • Search functionality by SAPID, message content, or employee name
  • Sort by most recent posts
  • Like system for appreciation posts

APIs Used:

GET /happenings
Retrieves all happenings with authentication middleware
POST /postlike
Handles like functionality with user SAPID details

Appreciate

Simple form with Recipient SAPID and appreciation message inputs

API Used:

POST /userappreciate
Submits appreciation data with SAPID and message details

Profile

Comprehensive user profile displaying:

  • Total appreciation received
  • Overall points achieved
  • Current rank
  • Project details
  • SAP ID and contact information

API Used:

GET /userprofile
Retrieves user profile data with web token authentication

About

Contains comprehensive project details and information

Logout

Secure session termination

API Used:

GET /logoutuser
Handles user session deletion and logout

Security Features

  • JWT Authentication - Secure token-based authentication
  • Password Encryption - Passwords stored in encrypted form
  • Admin Approval - New user requests require administrator approval
  • Session Management - Secure session handling and automatic logout
  • Input Validation - Client-side and server-side validation
