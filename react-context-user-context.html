React Context — UserContext (Context creation template)

This page documents a simple starter template for creating and using React Context to share a user object across your app.

Reference snippet

// 1. Create the context
export const UserContext = createContext();

// 2. Create the provider component
export const UserProvider = ({ children }) => {
  const [user, setUser] = useState(null);

  return (
    
      {children}
    
  );
};

Plain-English steps

Step 1: createContext()

createContext() makes a global container (a box) where you can store data. Normally React state is local to a component. Context lets you share state across many components without passing props down the tree.

Step 2: Provider

The Provider is the delivery mechanism. Everything you put in value={...} will be available to any component that subscribes to the context.

<UserContext.Provider value={{ user, setUser }}>
  {children}
</UserContext.Provider>

Step 3: Wrapping your app

Wrap your app so all children can access the shared values:

<UserProvider>
  <App />
</UserProvider>

Step 4: Consuming the context

Inside any component:

const { user, setUser } = useContext(UserContext);

This subscribes the component to the UserContext. You can read user and update it with setUser.

Quick summary

  • createContext() — makes the global container.
  • Provider — supplies values to the container.
  • useContext(SomeContext) — reads the values in a component.

Notes & suggestions

  • Keep the provider high in your component tree (often index.js or inside the root layout) so many components can access it.
  • For complex state, you can combine Context with useReducer or a state manager.
  • Export both the context and provider from a single module to keep imports simple.
