Insider Hub Frontend

Frontend

Front end part will be created with Stack - React with Vite, Tailwind CSS, JavaScript

Functionalities

Root Page

Login page contains the two button - Login , Request Access

Login - Reroutes to /login page

Request - Reroutes to /requestuser page

Login Page

Simple Login form which takes SAPID and Password as Input

Upon Clicking Sign in button

This will trigger the backend API with Post method /api/auth/login which shares the input data to backend to validate.

Request access button

Reroutes to /requestuser page

Request Access Page

Sign Up form requires SAPID, Full Name, Designation, Project, Password and Confirm Password, Email ID

All fields are mandatory field

Role, Creation time and Unique ID will be stored automatically.

Upon Clicking Request access button

This action triggers the backend API with a POST method to "/newUser," which shares the input data with administrators. It also sends an email to all admins, who can approve the request either through the admin panel or directly from the received email.

After successful approval from the administrator, users can log in with their SAPID and password.

Passwords are stored in encrypted form and cannot be viewed as plaintext (not even by administrators).

Home Page

After successful login, users will see the Home page.

It has the following 5 options:

  • View Happenings
  • Appreciate
  • Profile
  • About
  • Logout

Detailed explanation on each functionalities

View Happenings
  • This page displays all appreciation messages shared between teams and employees
  • You can search for specific content by SAPID, message content, or employee name
  • Appreciation posts can be sorted by most recent first
  • Users can like appreciation posts
APIs Used
  • A GET request to the "/happenings" endpoint will be made to the backend, requiring a web token/session token for user authentication through middleware before returning the requested details.
  • When a user clicks the like button, a request to the "/postlike" endpoint will be made to the backend with the user token through middleware. The user's SAPID details will be shared with this request.

Appreciate
  • This page contains a simple form with Recipient SAPID and appreciation mail as input
  • Upon clicking the data will be shared through post request
API Used
  • A Post request /userappreciate will be made to the backend with the details of SAPID and message

Profile
  • Logged in user profile details will be listed with Total appreciation, overall points achieved, Overall rank, Current project, Sap ID, Project name and contact details
  • A Get request /userprofile will be made to the backend with header contains the web token of the user which will be authenticated using middleware

About

Contains all details about the project.

Logout

Upon clicking user session will be deleted and user will be logged out

A Get request /logoutuser will be made to the backend.
